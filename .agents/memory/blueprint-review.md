**How to apply:** Preserve the original private document. Keep AI output unconfirmed until the user reviews it. Unreadable widths, direction and page proportions must remain unknown. Label normalized-source 3D as illustrative, not a cadastral survey or measured construction model.

**Why:** Visual interpretation is not permission to change operational or financial records.

**How to apply:** Keep visual geometry separate from project inventory and posted ledgers; require explicit review for replacement geometry. AI/provider failure must be visible, never replaced by invented geometry. Manual tracing is an explicit alternative, not a silent AI fallback.
