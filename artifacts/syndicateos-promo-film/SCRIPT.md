# SyndicateOS — one minute product film

## Director's treatment
- **Promise:** A shared operating picture for the people building a venture and the partners backing it.
- **Identity:** Brand-derived ink navy and warm ivory, with the logo's amber as the signal color. Syne display typography, DM Sans for interface copy, JetBrains Mono for scrubbed example metrics. The amber is interpreted from the supplied SOS mark, not an official documented brand token.
- **Hero:** A pair of fictionalized, privacy-safe interface worlds: the accountant's wide operations console and the partner's personal view. Neither uses the supplied captures; all interface data and names are fabricated and visibly illustrative.
- **Motion:** A gold orbital rule that becomes the ledger spine; high-speed camera pushes through data tiles; a split-screen aperture that connects the two user roles.
- **Arc:** Start with the cost of fragmented work, build through visibility and stewardship, then resolve in a calm shared-system brand lockup.
- **Payoff:** The closing frame unites accountant and partner panels into one mark and message rather than repeating a dashboard screen.
- **Format/runtime:** 16:9, 60 seconds.
